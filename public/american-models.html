OpenAI

Strengths: frontier reasoning, coding, broad ecosystem adoption.

  • gpt-5.5 — Current flagship general model. $5.00 / $30.00
  • gpt-5.4 — Strong lower-cost flagship tier. $2.50 / $15.00
  • gpt-5.4-mini — Cheaper fast tier for higher-volume applications. $0.75 / $4.50
  • gpt-5.3-codex — Coding-focused route. $1.75 / $14.00

Sources: OpenAI API pricing

Anthropic

Strengths: long-context reasoning, writing quality, safety-focused enterprise usage.

  • Sonnet 4.6 — General-purpose premium tier. $3.00 / $15.00
  • Opus 4.7 — Current top-capability tier. $5.00 / $25.00

Sources: Anthropic pricing · Claude API docs pricing

Google DeepMind

Strengths: multimodal performance, long context, broad model ladder.

  • gemini-3.1-pro-preview — Premium multimodal model. $2.00 / $12.00
  • gemini-3.1-flash-lite-preview — Fast low-cost tier. $0.25 / $1.50

Sources: Gemini API pricing

Amazon (AWS)

Strengths: enterprise distribution via Bedrock, broad deployment pathways, and price-performance model ladder.

  • amazon-nova-pro — General multimodal model via Bedrock. Pricing page confirms Nova model family, but this pass did not cleanly expose the token-rate rows for Nova Pro
  • amazon-nova-lite — Lower-cost tier for high-volume workloads. Pricing page confirms the Nova model family, but exact token rates should be rechecked live before publication-sensitive quoting

Sources: Amazon Nova models · Amazon Nova pricing · Amazon Bedrock pricing

NVIDIA

Strengths: agentic model stack (Nemotron), infrastructure-native deployment, and enterprise AI platform reach.

  • nemotron-3-super-120b-a12b — Open hybrid MoE profile for complex agent workloads. $0.15 / $0.65
  • nemotron-3-nano-30b-a3b — Efficiency-oriented smaller model for specialized agents. $0.06 / $0.24

Sources: NVIDIA Nemotron overview · NVIDIA developer page · Amazon Bedrock pricing

xAI

Strengths: strong general model profile with large-context support.

  • grok-4.20 — xAI's current recommended general model. Token pricing is shown on the model detail page rather than the main models list; this pass confirmed the current route name and tool pricing, but exact token rates should be rechecked on the live detail page before quoting

Sources: OpenRouter model page · xAI model docs

Meta
