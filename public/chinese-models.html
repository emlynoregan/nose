Chinese Models

Major Chinese model labs, rapidly improving value tiers, and competitive multimodal offerings.

← Back to AI overview

Alibaba (Qwen)

Strengths: quality-per-dollar, coding, long context, and increasingly broad multimodal coverage.

  • Qwen3-Max — Current top hosted flagship for harder reasoning and tool-heavy work. From $0.359 / $1.434 in global deployment; higher in some regional modes
  • Qwen3.5-Plus — Balanced text+image+video tier positioned as faster and more cost-effective than Max. From $0.115 / $0.688 in global deployment
  • Qwen3.5-Flash — Budget high-context route for simpler tasks. From $0.029 / $0.287 in global deployment

Sources: Alibaba Model Studio models & pricing

DeepSeek

Strengths: exceptional price-performance, long context, and strong coding/reasoning economics.

  • deepseek-v4-flash — Value flagship with both thinking and non-thinking modes. $0.14 input cache-miss / $0.28 output
  • deepseek-v4-pro — Premium tier for stronger capability at materially higher cost. $1.74 input cache-miss / $3.48 output

Sources: DeepSeek API pricing

MiniMax

Strengths: agentic workflows, coding, and a fast-moving release cadence across text, speech, music, and video.

  • MiniMax-M2.7 — Current M-series release as of March 2026, positioned as the next step after M2.5. $0.30 input / $1.20 output on OpenRouter
  • MiniMax-M2.5 — Prior 2026 generation still useful as a practical reference point for agentic and office-style tasks. $0.15 input / $1.15 output on OpenRouter

Sources: MiniMax model release notes · OpenRouter MiniMax-M2.7 pricing · OpenRouter MiniMax-M2.5 pricing

Zhipu (Z.ai)

Strengths: Chinese-language fluency, agentic engineering, and a growing full-stack platform around the GLM family.

  • GLM-5 — Current flagship positioned for coding and agent workloads. ¥4 input / ¥18 output per 1M tokens for prompts under 32k on Z.ai's rendered pricing page; higher tiers apply for longer prompts
  • GLM-5-Turbo — Lower-cost line optimized for fast inference, tool calling, and long-chain execution. ¥5 input / ¥22 output per 1M tokens for prompts under 32k on Z.ai's rendered pricing page; higher tiers apply for longer prompts
  • GLM-4.6V — Open visual-reasoning line for multimodal use cases. Current public pricing still needs a cleaner rendered-source confirmation here

Sources: Z.ai / Zhipu overview · Zhipu Open Platform pricing · OpenRouter GLM-5 pricing · OpenRouter GLM-5-Turbo pricing

Moonshot AI

Strengths: long-context quality, multimodal input, and increasingly agent-oriented positioning.

  • Kimi K2.6 — Moonshot's current most intelligent model, with text, image, and video input plus thinking and non-thinking modes. $0.7448 input / $4.655 output on OpenRouter
  • Kimi K2 Thinking — Reasoning-oriented K2 line for long-horizon agentic work. $0.60 input / $2.50 output on OpenRouter

Sources: Moonshot pricing hub · Moonshot pricing update post · OpenRouter Kimi K2.6 pricing · OpenRouter Kimi K2 Thinking pricing

Baidu

Strengths: enterprise positioning, broad multimodal research, and a large installed ecosystem around ERNIE.

  • ERNIE 5.0 — Current headline family in Baidu's own messaging, framed as a unified multimodal foundation model. Public first-party token pricing was still not cleanly confirmed here; use Baidu's Qianfan pages for publication-sensitive exact rates
  • ERNIE 4.5 21B A3B Thinking — Lightweight reasoning-oriented ERNIE route available through OpenRouter. $0.07 input / $0.28 output on OpenRouter
  • ERNIE 4.5 VL 28B A3B — Notable multimodal line highlighted in Baidu/OpenRouter catalogs. $0.14 input / $0.56 output on OpenRouter

Sources: ERNIE blog · Baidu Qianfan docs · OpenRouter ERNIE 4.5 21B A3B Thinking pricing · OpenRouter ERNIE 4.5 VL 28B A3B pricing

ByteDance

Strengths: broad multimodal product family, strong consumer product integration, and unusually rapid model iteration.

  • Seed2.0 — Current flagship family on ByteDance's public model page. ByteDance's public model catalog was clearer than its text-pricing extract in this environment; use live vendor pricing before quoting exact token rates
  • Seed OSS 36B Instruct — Open instruction-tuned reasoning model from ByteDance's Seed team, available on OpenRouter. OpenRouter lists the model, but the fetched page did not expose a clean token-price string in this environment, so treat pricing as provider-dependent until rechecked live
  • Seedance 2.0 / Seedream 5.0 Lite — Evidence of strong video/image specialization around the broader Seed family. Specialized media pricing varies by route

Sources: ByteDance Seed model catalog · OpenRouter Seed OSS 36B Instruct

Tencent

Strengths: practical enterprise deployment, API availability through Tencent Cloud, and broad product integration.

  • Tencent HY 2.0 Think — Current higher-end Hunyuan reasoning route in Tencent Cloud's pricing table. ¥3.975 input / ¥15.9 output per 1M tokens up to 32k input, rising to ¥5.3 / ¥21.2 for 32k–128k prompts
  • Tencent HY 2.0 Instruct — General-purpose 2.0 instruction tier below Think. ¥3.18 input / ¥7.95 output per 1M tokens up to 32k input, rising to ¥4.505 / ¥11.13 for 32k–128k prompts
  • Hunyuan-T1 / TurboS / a13b — Older and cheaper text routes still listed publicly. T1: ¥1 / ¥4; TurboS: ¥0.8 / ¥2; a13b: ¥0.5 / ¥2 per 1M tokens

Sources: Tencent Hunyuan pricing overview

Xiaomi

Strengths: emerging agentic coding performance, long-horizon task execution, and efficient harness-aware behavior.

  • MiMo-V2.5-Pro — Xiaomi's current public-beta flagship, now rolled out across its API platform and AI Studio. $1.00 input / $3.00 output on OpenRouter
  • MiMo-V2.5 — Lower-priced omnimodal sibling in the same public OpenRouter lineup. $0.40 input / $2.00 output on OpenRouter
  • MiMo-V2-Pro — Previous flagship still relevant mainly as a baseline for the 2.5-Pro upgrade. $1.00 input / $3.00 output on OpenRouter

Sources: Xiaomi MiMo-V2.5-Pro announcement · OpenRouter MiMo-V2.5-Pro pricing · OpenRouter MiMo-V2.5 pricing · OpenRouter MiMo-V2-Pro pricing
