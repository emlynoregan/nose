Chinese Models

Major Chinese model labs, rapidly improving value tiers, and competitive multimodal offerings.

← Back to AI overview

Alibaba (Qwen)

Strengths: quality-per-dollar, coding, long context, and increasingly broad multimodal coverage.

  • Qwen3-Max — Current top hosted flagship for harder reasoning and tool-heavy work. From $0.359 / $1.434 in global deployment; higher in some regional modes
  • Qwen3.5-Plus — Balanced text+image+video tier positioned as faster and more cost-effective than Max. From $0.115 / $0.688 in global deployment
  • Qwen3.5-Flash — Budget high-context route for simpler tasks. From $0.029 / $0.287 in global deployment

Sources: Alibaba Model Studio models & pricing

DeepSeek

Strengths: exceptional price-performance, long context, and strong coding/reasoning economics.

  • deepseek-v4-flash — Value flagship with both thinking and non-thinking modes. $0.14 input cache-miss / $0.28 output
  • deepseek-v4-pro — Premium tier for stronger capability at materially higher cost. $1.74 input cache-miss / $3.48 output

Sources: DeepSeek API pricing

MiniMax

Strengths: agentic workflows, coding, and a fast-moving release cadence across text, speech, music, and video.

  • MiniMax-M2.7 — Current M-series release as of March 2026, positioned as the next step after M2.5. Pricing varies by provider; check live platform quotes before publication-sensitive decisions
  • MiniMax-M2.5 — Prior 2026 generation still useful as a practical reference point for agentic and office-style tasks. Older routed prices may still appear, but should be treated as stale until rechecked

Sources: MiniMax model release notes · MiniMax platform docs

Zhipu (Z.ai)

Strengths: Chinese-language fluency, agentic engineering, and a growing full-stack platform around the GLM family.

  • GLM-5 — Current flagship positioned for coding and agent workloads. Official public pricing was not cleanly extractable in this pass; verify live platform pricing before quoting exact token rates
  • GLM-5-Turbo — Lower-cost line optimized for tool calling, instruction following, and long-chain execution. Pricing not quoted here because the official page was JS-gated in this environment
  • GLM-4.6V — Open visual-reasoning line for multimodal use cases. Varies by deployment/provider

Sources: Z.ai / Zhipu overview · Zhipu Open Platform pricing

Moonshot AI

Strengths: long-context quality, multimodal input, and increasingly agent-oriented positioning.

  • kimi-k2.6 — Moonshot's current most intelligent model, with text, image, and video input plus thinking and non-thinking modes. Moonshot clearly markets this as the current flagship, but the public docs visible in this environment did not expose a clean token-price table; verify the live pricing subpage before quoting exact rates
  • kimi-k2-thinking / kimi-k2-thinking-turbo — Reasoning-oriented K2 line highlighted in Moonshot's pricing update posts. Moonshot says input prices were cut by up to 75%, but the exact current token rates were not extractable here

Sources: Moonshot pricing hub · Moonshot pricing update post

Baidu

Strengths: enterprise positioning, broad multimodal research, and a large installed ecosystem around ERNIE.

  • ERNIE 5.0 — Current headline model family, framed by Baidu as a unified multimodal foundation model. Public token pricing was not confirmed in this pass; verify on Qianfan before publishing exact rates
  • ERNIE-4.5-VL-28B-A3B-Thinking — Notable multimodal reasoning line highlighted in recent Baidu research posts. Research/demo pricing varies by platform

Sources: ERNIE blog · Baidu Qianfan docs

ByteDance

Strengths: broad multimodal product family, strong consumer product integration, and unusually rapid model iteration.

  • Seed2.0 — Current flagship family on ByteDance's public model page. Pricing depends on the serving surface and was not confirmed in a clean public extract here
  • Seed1.8 / Seed1.6 — Earlier general-purpose families still visible in the public model lineup. Varies by platform
  • Seedance 2.0 / Seedream 5.0 Lite — Evidence of strong video/image specialization around the core text model family. Specialized media pricing varies

Sources: ByteDance Seed model catalog

Tencent

Strengths: practical enterprise deployment, API availability through Tencent Cloud, and broad product integration.

  • Tencent HY 2.0 Think — Current higher-end Hunyuan reasoning route in Tencent Cloud's pricing table. ¥3.975 input / ¥15.9 output per 1M tokens up to 32k input, rising to ¥5.3 / ¥21.2 for 32k–128k prompts
  • Tencent HY 2.0 Instruct — General-purpose 2.0 instruction tier below Think. ¥3.18 input / ¥7.95 output per 1M tokens up to 32k input, rising to ¥4.505 / ¥11.13 for 32k–128k prompts
  • Hunyuan-T1 / TurboS / a13b — Older and cheaper text routes still listed publicly. T1: ¥1 / ¥4; TurboS: ¥0.8 / ¥2; a13b: ¥0.5 / ¥2 per 1M tokens

Sources: Tencent Hunyuan pricing overview

Xiaomi

Strengths: emerging agentic coding performance, long-horizon task execution, and efficient harness-aware behavior.

  • MiMo-V2.5-Pro — Xiaomi's current public-beta flagship, now rolled out across its API platform and AI Studio. No price change from MiMo-V2-Pro according to Xiaomi, but exact token rates were not disclosed in the fetched page
  • MiMo-V2-Pro — Previous flagship still relevant mainly as a baseline for the 2.5-Pro upgrade. Check Xiaomi's live platform for current plan details

Sources: Xiaomi MiMo-V2.5-Pro announcement

Indicative pricing per 1M input/output tokens where directly confirmed from current public docs, quoted in vendor-listed currency (USD or RMB/Yuan as applicable). Last updated: April 2026.
